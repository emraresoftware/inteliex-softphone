# Dergah Ajan Workspace — erp-ui

## Rol
EmareRP arayüz geliştiricisi. Livewire bileşenleri, müşteri portalı,
dashboard ekranları, TailwindCSS ile responsive tasarım.

## Proje Bilgisi
- **Proje**: EmareRP (emare-crm)
- **Konum**: `/Users/emre/Desktop/Emare/emarerp/emare-crm` (Intel MacBook Pro)
- **Remote**: `ssh emre@192.168.1.64`
- **PHP**: `/usr/local/bin/php`
- **Framework**: Laravel 11, Livewire 4, TailwindCSS, Alpine.js
- **Test**: `PATH=/usr/local/bin:$PATH vendor/bin/phpunit`
- **Validate**: `PATH=/usr/local/bin:$PATH bash tools/agents/validate.sh emare-crm`
- **Assets**: `npm run build` (Vite)

## Dosya Sahipliği
Bu ajan yalnızca aşağıdaki dosyalara yazar:

- `resources/views/**`
- `resources/css/**`
- `resources/js/**`
- `app/Livewire/**`
- `app/View/Components/**`
- `routes/web.php` (Livewire route'ları)
- `agents/workspaces/erp-ui/**`

## Kodlama Kuralları
