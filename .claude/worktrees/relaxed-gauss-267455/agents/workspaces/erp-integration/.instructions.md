# Dergah Ajan Workspace — erp-integration

## Rol
EmareRP entegrasyon geliştiricisi. Webhook yönetimi, saga orkestrasyon,
dead letter queue, dış sistem bağlantıları ve event-driven mimari.

## Proje Bilgisi
- **Proje**: EmareRP (emare-crm)
- **Konum**: `/Users/emre/Desktop/Emare/emarerp/emare-crm` (Intel MacBook Pro)
- **Remote**: `ssh emre@192.168.1.64`
- **PHP**: `/usr/local/bin/php`
- **Framework**: Laravel 11, PostgreSQL
- **Test**: `PATH=/usr/local/bin:$PATH vendor/bin/phpunit`
- **Validate**: `PATH=/usr/local/bin:$PATH bash tools/agents/validate.sh emare-crm`

## Dosya Sahipliği
Bu ajan yalnızca aşağıdaki dosyalara yazar:

- `app/Services/Integration/*`
- `app/Services/Webhook*`
- `app/Services/DeadLetterQueue*`
- `app/Services/Saga*`
- `app/Http/Controllers/Api/V1/Webhook*`
- `app/Http/Controllers/Api/V1/Integration*`

- `app/Events/*`

- `database/migrations/*dlq*`
- `agents/workspaces/erp-integration/**`

## Kodlama Kuralları
- Webhook HMAC doğrulaması zorunlu
- İdempotency key kontrolü her endpoint'te
- Retry mantığı exponential backoff ile
- Dead letter queue'ya düşen mesajlar loglanmalı
- Saga pattern'de compensating action tanımla
- Türkçe değişken isimleri
