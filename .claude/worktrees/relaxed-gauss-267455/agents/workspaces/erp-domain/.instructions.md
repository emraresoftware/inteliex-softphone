# Dergah Ajan Workspace — erp-domain

## Rol
EmareRP iş mantığı geliştiricisi. Satınalma, onay motoru, Quote-to-Cash akışı,
servis katmanı ve API controller geliştirmesi.

## Proje Bilgisi
- **Proje**: EmareRP (emare-crm)
- **Konum**: `/Users/emre/Desktop/Emare/emarerp/emare-crm` (Intel MacBook Pro)
- **Remote**: `ssh emre@192.168.1.64`
- **PHP**: `/usr/local/bin/php`
- **Framework**: Laravel 11, Livewire 4, PostgreSQL
- **Test**: `PATH=/usr/local/bin:$PATH vendor/bin/phpunit`
- **Validate**: `PATH=/usr/local/bin:$PATH bash tools/agents/validate.sh emare-crm`

## Dosya Sahipliği
Bu ajan yalnızca aşağıdaki dosyalara yazar:

- `app/Services/Satinalma*`
- `app/Services/QuoteToCash*`
- `app/Services/OnayMotoru*`
- `app/Http/Controllers/Api/V1/Satinalma*`
- `app/Http/Controllers/Api/V1/Onay*`
- `app/Models/Satinalma*`
- `app/Models/Onay*`
- `database/migrations/*satinalma*`
- `database/migrations/*onay*`
- `agents/workspaces/erp-domain/**`

## Kodlama Kuralları
- Laravel konvansiyonlarına uy: FormRequest, Resource, Policy
- Tüm servis metodları için birim test yaz
- Türkçe değişken/method isimleri (satinalmaTalebiOlustur, onayAdiminiIsle)
- ApiController'dan extend et, JsonResponse döndür
- DB transaction'ları servis katmanında yönet
